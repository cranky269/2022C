## 3. 缺失模式分析

### 3.1 两列缺失完全共现

| 组合 | 记录数 |
|---|---|
| 温度与不确定性**同时**缺失 | 11,002 |
| 仅温度缺失 | 0 |
| 仅不确定性缺失 | 0 |

两个数值列的缺失完全同步，属**结构性同缺**（同一条观测记录整体缺失），而非随机单点损坏。这意味着：

- 不存在"有温度但无不确定性"（或反之）的记录，可放心把两列当作一个整体做缺失处理；
- 温度缺失率 = 不确定性缺失率，二者不能互相插补。

### 3.2 真缺失 vs. 结构性缺失（时间覆盖）

| 项目 | 数值 |
|---|---|
| 理论完整网格（3,239 月 × 100 城） | 323,900 |
| 实际记录数 | 239,177 |
| 网格缺口 | **84,723（26.16 %）** |
| 存在"整月整行缺失"的城市数 | **0** |

即：**每座城市在其自身起止区间内，逐月都有对应记录行，从未出现整行跳过**。84,723 条的网格缺口全部来自"城市序列起始年份不同"，而不是文件缺行。

- 各城市结束月份统一为 **2013-09**；
- 起始年份共有 **28 种**，最早 1743-11（Berlin、Chicago、Istanbul、Kiev、London、Madrid、Montreal、Moscow、New York、Paris、Rome、Saint Petersburg、Toronto 共 13 城），最晚 1881-03（Lima）；
- 因此 `AverageTemperature` 的"缺失"实质是三类混合：
  1. 城市尚不存在时的**空档**（结构性，不应插补）；
  2. 存在但未观测的**真缺失**（11,002 条，4.60 %）；
  3. 数据尾部截断（2013-09 大面积空缺）。

### 3.3 数据尾部截断

2013-09 当月 100 条记录中 **93 条温度为空**，仅有 Chicago、Los Angeles、Mexico、Montreal、New York、Santo Domingo、Toronto 共 7 城有值。这是数据集的时间截断边界，而非观测缺失，建模时应直接截到 2013-08。

## 8. 其他数据质量问题（非缺失，但影响建模）

| 问题 | 详情 | 影响 |
|---|---|---|
| **文件编码** | GB18030/GBK，UTF-8 解码在偏移 721,440 处失败（字节 `0xa8`） | 用 `encoding='utf-8'` 读取会直接报错或产生乱码（如 `Bogot¨¢`、`Bras¨ªlia`） |
| **`dt` 双格式** | `YYYY-MM-DD` 102,677 行 + `YYYY/M/D` 136,500 行（后者月/日不补零） | 直接字符串排序、切片取月份（`dt[5:7]`）会得到 `1/` 之类的错误值；须用 `pd.to_datetime(..., format='mixed')` |
| **坐标非数值** | `Latitude`/`Longitude` 带 N/S/E/W 后缀，格式 100 % 合规无异常 | 需剥离后缀并按半球赋负号：北纬 81 城 / 南纬 19 城，东经 78 城 / 西经 22 城 |
| **非 ASCII 城市名** | 2 个：`Bogotá`、`Brasília` | 跨表连接 / 文件导出时易因编码不一致对不上 |
| **数值可解析性** | 非缺失值 100 % 可转 float，无异常字符串 | 无隐藏脏值 |
| **数值范围** | 温度 [-26.772, 38.283] ℃，均值 18.126；不确定性 [0.040, 14.037] ℃，均值 0.969 | 无极端离群到物理不可能的值，但需按城市另行做异常检测 |
| **重复记录** | `dt`+城市 重复 0 条 | 无需去重 |

缺失值判定说明：本数据缺失为**空字符串**，若使用 `pandas.read_csv` 默认参数，`AverageTemperature` 会因大量空值被推断为 object 类型，而不会作为 NaN 报出，容易漏检。本报告统一采用"去空格 + 转小写 + 命中 `{'', 'na', 'nan', 'n/a', 'null', 'none', '-', '?', '--'}`"的判定口径。

## 9. 结论与处理建议

### 9.1 结论

1. **缺失集中在两个温度数值列，共 11,002 条（4.60 %），两列完全同步缺失**，不存在单列损坏。
2. **文件本身无缺行、无重复主键**；26.16 % 的"网格缺口"源于各城市起始年份不同，属结构性空档，不是数据缺陷。
3. **缺失与时间强相关、与季节无关**：1900—2009 年零缺失，缺失几乎全部集中在 1900 年以前（尤其 1860s，缺失率 22.69 %）以及 2013-09 的尾部截断。
4. **缺失与空间强相关**：热带、非洲、东南亚城市缺失率最高（Dar Es Salaam 19.29 %），欧美城市最低（Los Angeles、Mexico 为 0）。
5. **缺失片段两极分化**：51.5 % 为单月孤立缺失，另有 28 段长达 30 年以上，后者不可插补。

### 9.2 建议

| 场景 | 建议 |
|---|---|
| 读取数据 | `pd.read_csv(path, encoding='gb18030', keep_default_na=False)`，再显式把空串转 NaN；日期用 `format='mixed'` |
| 主建模样本 | 直接截取 **1900-01 ~ 2013-08**（136,400 条，100 城，零缺失的平衡面板），既可回避全部插补问题，又能覆盖全球变暖的主要信号期 |
| 若必须用全时段 | 对 ≤2 个月的短缺口用**城市内月度线性/样条插值**；对 ≥12 个月的长缺口不要插值，改为标记掩码（missing mask）或在模型中设权重为 0 |
| 交叉验证 | 不要随机划分训练/测试集（会造成时间泄漏）；应按时间切分（如 1900—1990 训练、1991—2013 测试） |
| 不确定性列 | 因与温度完全同缺，插补温度时不确定性无法同步获得；建议对插补点显式赋一个较大的不确定性（如该城历史分位数上界），避免后续加权时低估误差 |
| 尾部 | 统一截止到 2013-08，剔除 2013-09 的 100 条记录（其中 93 条为空） |
| 城市名 | 统一 UTF-8 落地后使用，`Bogotá`、`Brasília` 需注意重音字符的规范化（NFC） |
